## 2025-05-14 - Lenco Webhook Authentication Bypass and Timing Attack
**Vulnerability:** The Lenco webhook endpoint was vulnerable to authentication bypass if the `LENCO_WEBHOOK_HASH_KEY` environment variable was missing or if the `x-lenco-signature` header was not provided. It also used a standard string comparison (`!==`) for signature verification, which is susceptible to timing attacks.
**Learning:** Webhook handlers often have a "fail-open" pattern when configuration is missing, which can lead to complete authentication bypass in production if environment variables are not correctly set. Standard string comparisons leak information about the correct signature through the time taken to return a result.
**Prevention:** Always implement "fail-secure" logic for webhooks: reject requests if keys or signatures are missing. Use `crypto.timingSafeEqual` for all cryptographic signature comparisons to prevent timing attacks, and ensure input buffers are compared for equal length beforehand to avoid runtime exceptions.
