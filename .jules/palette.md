## 2025-05-15 - Refined Redirects
**Learning:** Replacing native browser `alert()` with a stateful countdown UI improves UX by being non-blocking, providing visual progress, and offering user agency via a manual override button. Using existing icon libraries like `lucide-react` ensures visual consistency without adding font-loading overhead.
**Action:** Prioritize refactoring blocking alerts in other parts of the application (e.g., admin panels) to similar custom feedback components.
